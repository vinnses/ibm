# Human Review and Access Questions

These records contain only questions that an agent cannot responsibly resolve from authorized repository evidence and public sources. They are separate from agent-correctable errors.

Each question records:

- stable question ID;
- related Work and evidence gap;
- why agent work is insufficient;
- exact decision, document, or access needed;
- consequence for the current gate and later analysis;
- status and response provenance.

A pending human question does not automatically block a bounded public-source Work. Its record must say whether the applicable acceptance criterion permits an explicit `not located` or indeterminate status.
