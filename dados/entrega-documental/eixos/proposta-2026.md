# Documentary axis: 2026 proposal

## Scope and status

This axis contains the preserved 2026 internal call, the Biomedical Informatics proposal form and contextual pages. The repository evidence establishes a proposal document. It does not establish selection, approval, authorization or implementation.

## Preserved proposal documents

- [Edital 01/2026 PROGRAP/PROPLAD](../../../administracao/mec/2026/edital-01-2026-prograp-proplad.pdf) — internal call preserved as a source document.
- [Apêndice B — proposal form](../../../administracao/mec/2026/apendice-b-proposta-informatica-biomedica.pdf) — proposal content, including the document's own claims; claims remain claims of the proposal unless independently evidenced.
- [UFPR dialogue/context page](../../../administracao/mec/2026/fontes-complementares/ufpr-dialogo-edital-01-2026.html) — contextual public source.
- [Proposal source records](../../../administracao/dados/fontes.csv) and [historical source manifest](../../../administracao/historico/fontes/manifesto.csv) — provenance and hashes for the preserved files.

## Existing registers and boundaries

- [Administrative transition register](../../../administracao/historico/transicoes.csv) — separates proposal, selected, approved, authorized and implemented states; do not advance a state without its own evidence.
- [Historical negative-search register](../../../administracao/historico/buscas-negativas.csv) — bounded public gaps for the later process.
- [Original-act searches](../../../administracao/historico/atos-originais/buscas.csv) — search records, not substitutes for missing acts.
- [W011 human review](../../../governance/human-reviews/W011-p1-admin-procedure.md) — actionable protected-access questions for the process, matrix, PPC, equivalences, staffing, submission and later decisions.

The proposed 2,700-hour matrix, component/equivalence table, PPC, minutes, staffing guarantees, submission record and later decision acts are not treated as present merely because the proposal mentions them. No current compliance, offering or implementation statement belongs in this axis.
