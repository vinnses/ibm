# W035 argument sources

This directory preserves external public sources first used by W035. Original
downloaded bytes are unchanged. `manifest.csv` records provenance, access date,
version/date, SHA-256, and evidentiary purpose.

The AIMA author site was not accepted as a source on 2026-09-09 because the
Berkeley host redirected it to an IRIS service-outage page and the detailed
contents path returned HTTP 404. That access event is recorded as E-W035-001.
Search-engine cache text is not repository evidence.

The preserved Pearson page establishes that the product is the fourth edition,
identifies Stuart Russell and Peter Norvig, labels the page “Published by
Pearson (21 December 2021) © 2022,” separately lists a 2020 print ISBN, and
publishes a 27-chapter contents list. W035 therefore does not flatten the
edition's variant publication metadata into an unqualified “2022 edition.”
