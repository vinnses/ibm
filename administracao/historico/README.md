# W011 administrative and procedural register

This directory is the bounded W011 register. It records documentary status; it does not assess curricular quality or recommend a change.

- `transicoes.csv` separates authorization, recognition, the 2022 reform approval, and every 2026 proposal stage. `not_located` is a dated public-search result, never evidence of nonexistence.
- `avaliacoes.csv` keeps registry, CPA, INEP, Enade, and e-MEC fronts distinct. The CPA workbook is preserved unchanged and is not aggregated because the public file does not state its response denominator or aggregation method.
- `series-complementares.csv` preserves only stated universes. No row estimates applicant counts, final occupancy, or a cutoff score from an unmatched source.
- `buscas-negativas.csv` makes all required unresolved public fronts reproducible by recording domains, terms, date, results, and limits.

Sources already preserved elsewhere in the repository remain at their stable original paths and are recorded in the local source manifest. W011's new original captures are under `fontes/`.
