# W026 historical applicant-count search

H1 preserves literal NC/UFPR course-level applicant fields for 2015 and 2017. The counts retain their stated categories: 2015 `Concorrentes` excludes separately reported treineiros, while 2017 is the report's `Total Geral de Inscritos no Curso`. Neither value is derived from a candidate/vacancy ratio or an unmatched vacancy act.

H2 records no count for the 2017/2018 process after three bounded official-public attempts. For 2018/2019 it preserves only the source-stated `37` in `Concorrência Geral` among candidates called to the second phase. It is explicitly not a total-course count and no category values are summed.

H3 preserves the definitive-homologated `Concorrência Geral` category values: `38` for 2020/2021 and `44` for 2021/2022. Both source pages separately state treineiros and other categories. Those records are neither totals nor category sums.
