# Documentação administrativa

Este diretório reúne fontes sobre processos decisórios e condições institucionais do curso. Ele é mantido separado das reconstruções curriculares.

A presença de um documento neste diretório não significa concordância com suas alegações nem comprova que uma proposta tenha sido aprovada ou implementada. Cada conjunto documental deve registrar seu estágio administrativo e as verificações ainda pendentes.
